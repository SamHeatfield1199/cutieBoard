# CutieBoard

Милая Kanban-доска с розовой темой, построенная на React + TypeScript + MobX.
<img width="1918" height="909" alt="image" src="https://github.com/user-attachments/assets/21efee3c-25fb-4045-a8c2-54af4fdc3636" />

## Возможности

- **Несколько досок** - создавайте, переключайте и удаляйте доски из боковой панели
- **Шаблоны** - два готовых шаблона: Sprint Board (5 колонок) и Personal Tasks (4 колонки)
- **Карточки** - добавление, редактирование (заголовок + лейбл) и удаление карточек
- **Drag & Drop** - перетаскивание карточек между колонками и внутри колонки (HTML5 DnD)
- **Колонки** - добавление и удаление колонок на любой доске
- **Фильтрация** - поиск по тексту и фильтр по лейблу (UI/UX, Dev, Research, Design, QA)
- **Настройки** - имя рабочего пространства, 5 акцент-цветов, компактный режим, сброс данных
- **Персистентность** - все данные хранятся в `localStorage`, без бэкенда

## Стек


| Слой   | Технология               |
| ------ | ------------------------ |
| UI     | React 19 + TypeScript    |
| Стейт  | MobX 7 + mobx-react-lite |
| Сборка | Vite 8                   |
| Стили  | CSS Modules              |
| Тесты  | Jest + Testing Library   |
| Линтер | oxlint                   |


## Быстрый старт

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173).

## Команды

```bash
npm run dev      # дев-сервер с HMR
npm run build    # production-сборка
npm run preview  # предпросмотр сборки
npm test         # unit-тесты
npm run lint     # линтер (oxlint)
```

## Структура проекта

```
src/
├── stores/
│   └── BoardStore.ts          # MobX AppStore: доски, настройки, маршрутизация
├── types/
│   └── kanban.ts              # TypeScript-типы досок, карточек и настроек
├── templates/
│   └── templates.ts           # Определения шаблонов Sprint и Personal
└── components/
    ├── Sidebar/               # Боковая панель, список досок, модал создания
    ├── Board/                 # Доска, шапка, фильтр, форма добавления колонки
    ├── Column/                # Колонка, форма добавления карточки
    ├── Card/                  # Карточка, форма редактирования
    ├── Templates/             # Страница шаблонов
    └── Settings/              # Страница настроек
```

## Данные

Все данные сохраняются в `localStorage` под ключом `cute-kanban-app`. При первом запуске автоматически создаётся доска-пример с тремя колонками. Старый формат данных мигрирует автоматически.
